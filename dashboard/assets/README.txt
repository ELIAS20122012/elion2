Put the portrait used by the Elion AI card here as:  face.png

It is the same image as `assets/face.png` in the claude.ai/design project
"سکشن متحرک مشن گرافی" (1536x1024 PNG). The file is larger than what the
design API will hand over in one piece, so download it from the design
project and drop it in this folder.

Without it the card still animates correctly - the photo layer just hides
itself and a soft gold glow stands in.
