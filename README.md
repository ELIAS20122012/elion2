# Elion Pen (InkFlow)

On-screen pen / drawing app for Windows (C#, WPF, .NET).

- Source: `InkFlowRebuild/` (`InkFlow.csproj`)
- Build: `BUILD-elion.bat` (output goes to `InkFlowRebuild/publish`, not in git)
- Icons: `logo/`, `elion_icon_1024.png`, `refresh-icons.bat`

Part of Elion — see branch `main` of this repo.
