Elion Trading Dashboard - نسخه آماده برای سایت
================================================
index.html          -> صفحه اصلی داشبورد
journal.dc.html     -> صفحه ژورنال (از منوی Journal باز می شود)
ElionAICard.dc.html -> کارت متحرک ELION AI (داخل داشبورد لود می شود)
support.js, vendor/, assets/ -> فایل های لازم؛ حذف نکنید

همه فایل ها باید کنار هم در یک پوشه روی سرور باشند.
مستقیم با دوبار کلیک (file://) باز نمی شود؛ باید از طریق سرور یا هاست باز شود.

تست روی کامپیوتر خودتان:
  داخل همین پوشه:  python -m http.server 8000
  بعد در مرورگر:   http://localhost:8000
