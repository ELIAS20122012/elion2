# نظم (Daily Order، نسخه‌ی جدید)

اپ شخصی فارسی، موبایلی و ساده. سبک: زمینه‌ی کرم، کارت‌های استخوانی با سایه‌ی نرم، سبز تیره (رنگ اصلی) و مرجانی کم‌رنگ (تأکید)، نوار پایین ثابت.
داده‌ها فقط در `localStorage` (کلید `daily-order-v2`، سازگار با اپ قبلی). بدون بیلد و بدون وابستگی.

## ساختار (طبق پلن)
نوار پایین: **امروز · کارها · ورزش · مالی · خرید** — تنظیمات (چرخ‌دنده) و پروفایل (آواتار) از بالای صفحه.
هر صفحه: عنوان کوتاه ← **یک خط نوشتن بالا با دکمه‌ی کوچک ↵** (تایپ کن و Enter بزن؛ مستقیم در لیست می‌نشیند) ← کشوهای متنی همان بخش (یکی باز) ← کارت اصلی و فهرست.
خط نوشتن بسته به کشوی بازِ بخش کار می‌کند: کار/قرار · حرکت · «ماست ۱۲۰» = غذا با کالری · «نهار ۱۲۰» = هزینه و «+حقوق ۱۵۰۰» = درآمد · نام خرید.

- **امروز**: خوشامد، تاریخ، کارت «تمرکز امروز» (کار بعدی + «انجام شد»)، کار باقی‌مانده، وضعیت ورزش، خرج امروز، نزدیک‌ترین قرار.
- **کارها**: تقویم (هفته + نقطه‌ی قرار/کار) · قرارها (ترمین/ملاقات/جلسه/یادآور با ساعت و مکان) · کارهای روزانه (تکرار روزانه/هفتگی).
- **ورزش**: برنامه تمرین (۷ روز، ست‌ها، زمان‌سنج، پایان تمرین) · کالری (هدف، پروتئین، روند هفتگی) · عکس غذا (تخمین کالری/پروتئین، اصلاح، تاریخچه).
- **مالی**: خلاصه (موجودی، خرج امروز/ماه، بودجه‌ی باقی‌مانده، نزدیک‌ترین قسط) + تب‌ها: تراکنش‌ها (جست‌وجو/فیلتر) · قسط‌ها (فهرست ساده‌ی پرداخت‌های ماهانه: برق، اینترنت، قسط ماشین…؛ نام + مبلغ + تیک «این ماه پرداخت شد»، بدون وام/سررسید) · بودجه (ماهانه + هر دسته) · گزارش (نمودار ساده).

تخمین کالری از عکس: داخل آرتیفکت Claude خودکار؛ در مرورگر معمولی با کلید Gemini در «تنظیمات» (کلید جدا از داده‌ها و بیرون از بکاپ).

## اجرا و بیلد
```
cd apps/nazm && python3 -m http.server 8765          # http://localhost:8765/
node apps/nazm/tools/build.mjs                       # → dist/nazm.html (فایل تکی؛ از file:// هم باز می‌شود)
node --test "apps/nazm/tests/*.test.js"
```

## کد
`css/` توکن‌ها و استایل · `src/core` (state، تاریخ شمسی، فرمت) · `src/domain` (finance, tasks, gym, appointments, shopping؛ بدون DOM) ·
`src/ui` (sheet/toast/delegate + `kit.js`: تب، ردیف، حلقه، + شناور) · `src/features` (دیالوگ‌های کوتاه) · `src/pages` (today, tasks, gym, money) · `src/services`.
صفحه: `{ id, title, render() → html, act, input?, mount? }`؛ رویدادها با `data-act`؛ بعد از تغییر state: `commit()`؛ تب فعال هر بخش در `S.ui.tabs` می‌ماند.

- **خرید** (بخش جدا): فهرست خرید هفتگی؛ شبکه‌ی دوستونه‌ی اسم‌ها با یک تیک کوچک (لمس = خریده شد، نگه‌داشتن = ویرایش/حذف)، بدون دسته‌بندی.
