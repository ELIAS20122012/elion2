# نظم (Daily Order، نسخه‌ی جدید)

اپ شخصی فارسی، ساده و حرفه‌ای: **چهار تب** — خانه، ورزش، پول، من. بدون بیلد و بدون وابستگی؛ داده‌ها فقط در `localStorage`.
طراحی: سبز زیتونی تیره روی کرم، کارت‌های تخت با خط نازک، نوار ناوبری سبز پایین (مرجع: تصویر MOYA). تک‌تم (بدون حالت تاریک).

- **خانه**: خلاصه‌ی امروز (کارها، ست‌ها، کالری)، لیست کارها با افزودن سریع، عادت‌ها.
- **ورزش**: نوار «برنامه باشگاه» → هفت روز → برنامه‌ی همان روز (ست‌ها، ویرایش) → کالری همان روز + «عکس غذا» (تخمین و ذخیره روی همان روز) یا ورود دستی.
- **پول**: موجودی، هزینه/درآمد، سررسید نزدیک با پرداخت یک‌لمسی (واگرد دارد)، اخیر؛ قسط/قبض/حساب پشت یک لینک.
- **من**: وزن، هدف کالری، تنظیمات (نام، واحد پول، تقویم، کلید Gemini)، پشتیبان‌گیری.

تشخیص کالری از عکس: داخل آرتیفکت Claude خودکار؛ در مرورگر معمولی با کلید Gemini در «من ← تنظیمات» (کلید جدا از داده‌ها و بیرون از بکاپ).

## اجرا و بیلد
```
cd apps/nazm && python3 -m http.server 8765          # http://localhost:8765/
node apps/nazm/tools/build.mjs                       # → dist/nazm.html (فایل تکی؛ از file:// هم باز می‌شود)
node --test "apps/nazm/tests/*.test.js"
```

## ساختار
`css/` توکن‌ها و استایل · `src/core` (state، تاریخ شمسی، فرمت) · `src/domain` (مالی، کارها، ورزش؛ بدون DOM) ·
`src/ui` (sheet/toast/delegate) · `src/features` (دیالوگ‌ها) · `src/pages` (home, gym, money, me) · `src/services` (فایل، AI، اعلان).
صفحه: `{ id, title, render() → html, act, hold, mount? }`؛ رویدادها با `data-act`. بعد از تغییر state: `commit()`.
کلید ذخیره `daily-order-v2` است، پس داده‌های اپ قبلی (`apps/daily-order`) خوانده می‌شوند.
